## Что умеет

- Снимок области, окна под курсором (по клику) или всего экрана.
- Снимок по таймеру: программа помнит прошлую рамку, отсчёт идёт по живому
  экрану — можно открыть меню или подсказку и снять их.
- Разметка поверх кадра: карандаш, линия, стрелка, прямоугольник, маркер,
  текст, выбор цвета и толщины, отмена.
- Сохранение в PNG или JPEG и копирование в буфер.
- Перевод текста на снимке — кнопка **АЯ** или <kbd>Ctrl</kbd>+<kbd>T</kbd>.
  Распознавание работает офлайн средствами Windows, в интернет уходит только
  распознанный текст и только с вашего разрешения.
- Русский и английский интерфейс, переключается в настройках.

## Установка

Скачайте архив из раздела [Releases](../../releases), распакуйте и запустите
**`Установить PyShot.bat`**. Программа встанет в `C:\Program Files\PyShot`,
появится в меню «Пуск» и в списке установленных программ.

Удаление — *Параметры → Приложения → PyShot → Удалить*. Настройки и снимки
остаются на месте.

Из исходников:

```bash
python -m pip install -r requirements.txt
pythonw main.py
```

Нужны Windows 10 или 11, Python 3.10+ и PySide6 — других зависимостей нет.

## Горячие клавиши

| Сочетание | Действие |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>4</kbd> | снимок области или окна |
| <kbd>Ctrl</kbd>+<kbd>5</kbd> | весь экран |
| <kbd>Ctrl</kbd>+<kbd>6</kbd> | снимок запомненной рамки по таймеру |

Меняются в настройках. В окне выделения: <kbd>Enter</kbd> — сохранить,
<kbd>Ctrl</kbd>+<kbd>C</kbd> — скопировать, <kbd>Ctrl</kbd>+<kbd>Z</kbd> —
отменить, <kbd>Esc</kbd> — закрыть.

Значок в трее: левый клик — настройки, правый — меню.

## Настройки

Папка для снимков (по умолчанию `Рабочий стол\Скриншоты`), формат и качество
файла, шаблон имени, горячие клавиши, язык, задержка таймера, автозапуск
вместе с Windows, параметры перевода.
